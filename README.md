# 身份认知插件（Alcpare.identity）

让她知道**当前跟她说话的人是谁**（主人 / 朋友 / 群友），从而用对态度；还能上传画像，让她记住**自己长什么样**。

纯手动白名单，**不调用任何 LLM 判断身份、不写宿主数据库、没有定时任务**。

| 项目 | 说明 |
|---|---|
| 当前版本 | **2.0.0** |
| 兼容 | MaiBot **1.3.19 ~ 1.4.99** / 插件 SDK **2.9.0 ~ 2.22.99** |
| 需要能力 | `custom_pages`、`image_upload` |
| 反馈 | [Issues](https://github.com/Alcpare/maibot_identity_plugin/issues) |

---

## ✨ 功能一览

### 身份认知

- **三档内置态度**：主人 / 朋友 / 群友，每档可单独改文案。
- **自定义身份档位**：想加「同事」「父亲」「女朋友」都行，每档写独立提示词。
- **关心频率**：四档（不提 / 偶尔 / 正常 / 经常），控制她主动关心的分寸。
- **名单外的人**：可指定按哪一档对待，也可关掉省 token。

### AI 画像

- **上传图片**：自动调用视觉模型生成外形描述（发色瞳色、服装、姿态）。
- **手写补充**：可与自动描述拼接，也可只用文字。
- **注入位置**：身份之后紧跟一行「你长这样：…」。

### 界面

- **扇形图**：每人一块，按（聊天次数 + 注入次数）占比排序。
- **排行榜**：名次、身份、QQ 号，与扇形颜色一一对应。
- **运行统计**：累计轮次、今日活跃人数、运行时间（每秒刷新）。

### QQ 命令

全部需要 **operator 权限**（`bot_config.toml` 的 `permission` 列表）。

| 命令 | 作用 |
|---|---|
| `/identity` | 查看名单 |
| `/identity <QQ> <身份名>` | 添加或修改身份 |
| `/identity del <QQ>` | 移除 |
| `/image` | 查看画像描述 |
| `/image add <描述>` | 追加画像描述 |
| `/image clear` | 清空画像 |

## 🚀 一分钟上手

### 方式一：WebUI 图形界面（推荐）

1. 在 WebUI 插件页确认本插件已加载。
2. 打开侧边栏的 **「身份认知」** 页面。
3. 点「+ 添加身份」→ 填 QQ 号 → 选身份 → 拖关心频率。
4. 想加画像就上传一张图，会自动识别。

**保存即生效，不用重启** ✓

### 方式二：直接改配置

```toml
[identity]
roster = [
  { user_id = "100000001", label = "主人", care_level = 4 },
  { user_id = "100000002", label = "朋友", care_level = 2 },
]
```

也兼容旧版的多行文本写法（会自动迁移成上面的列表格式，旧配置升级不会丢名单）：

```toml
roster = """
100000001 = 主人
100000002 = 朋友        # 也可以写注释
"""
```

**不用写名字**：她在聊天里看到的显示名（群名片优先，其次昵称）会实时取用，所以你或对方改群名片、改昵称都不影响。

## 配置项

### 1️⃣ 名单（`roster`）

每项三个字段：

| 字段 | 说明 |
|---|---|
| `user_id` | QQ 号，只用于内部识别，**永不进入提示词** |
| `label` | 身份档位，可填内置三档或自定义档位名 |
| `care_level` | 关心频率 1~4（不提 / 偶尔 / 正常 / 经常） |

### 2️⃣ 三档语气文案

改这三段就能调她的分寸：

```toml
owner_style  = "「主人」档的态度"
friend_style = "「朋友」档的态度"
member_style = "「群友」档的态度"
```

### 3️⃣ 关心频率措辞

```toml
care_none   = "这一档不用主动关心对方…"
care_rare   = "关心的话偶尔提一句就够…"
care_normal = "可以自然地关心，一两句就够…"
care_often  = "可以多关心几句，也可以多问一句…"
```

### 4️⃣ 开关（默认值就是推荐值）

| 配置 | 默认 | 说明 |
|---|---|---|
| `inject_to_planner` | `true` | 在 planner 阶段注入（决定怎么回） |
| `inject_to_replyer` | `true` | 在 replyer 阶段注入（决定说什么） |
| `inject_for_others` | `false` | 名单外的人也注入（开=更自然，关=省 token） |
| `log_injections` | `false` | 每次注入写日志，方便核对 |

### 5️⃣ 自定义档位（`custom_styles`）

```toml
[identity.custom_styles]
"同事" = "跟你说话的是同组同事，客气但不热乎。"
"父亲" = "这是你父亲，说话可以随意些，但别顶撞。"
```

## 它到底往提示词里塞了什么

注入的是一段**独立的内部说明**，不含任何 QQ 号：

```
【内部参考 · 只给你自己看，不要向别人解释或复述这份说明】
- 本条消息来自：老王（你的父亲）。……
- 你长这样：银发红瞳的少女，穿白色连衣裙。
- 其他所有人按普通群友对待：……
- 这是你的内部认知，正常聊天时不用提它，也别主动给谁贴"档位"标签；
  但如果对方问起你们的关系，就自然承认、按关系说话，不用回避。
```

设计上刻意做了三件事：

1. **号码零泄漏**：注入前有脱敏自检，5 位以上连续数字一律打码。
2. **防伪造**：只认自己注入的 `SystemMessageItem`（按 item_id 前缀），用户在正文里打标记无效。
3. **防跨会话冒充**：消息 ID 必须属于当前会话，否则不认。

---

## 设计要点

- **三个钩子都是 SDK 正式内置 Hook**，不依赖私有接口。
- **统计节流**：每 20 秒才落盘一次，热群里不会卡事件循环。
- **原子写**：配置走 `tmp + os.replace`，序列化失败也不会得到 0 字节文件。
- **图片零 RPC**：上传走宿主 `uploads` 通道，文件字节不经过 JSON。

## 排查

日志里搜 `[身份]`：

```
[身份] 已加载：名单 4 人（389***516→朋友、…）
[身份] 已注入(planner/…)
[身份][画像] 已保存画像 xxx：银发红瞳的少女…
```

常见问题：

| 现象 | 原因 |
|---|---|
| 命令执行了但没回复 | `_manifest.json` 缺 `send.text` 能力声明 |
| 页面加载失败 | 插件未加载完，或 `webui.json` 引用了未注册的 API |
| 上传没反应 | 缺 `image_upload` 能力声明，或图片不是 JPEG/PNG/WebP |
| 注入不生效 | `inject_for_others=false` 且对方不在名单里 |

---

## 已知限制

- **只认手动名单**：不做自动识别、不猜关系。
- **单会话单说话者**：一次注入只对应一条消息的发送者。
- **画像最多 5 张**：注入时只取前 2 条、每条 80 字。

## 更新日志

### v2.0.0（正式版）

首个正式版本。相比 v1.x 测试版：

**新功能**

- AI 画像：WebUI 上传图片自动识别外形，支持手写补充；QQ 命令 `/image` 管理。
- 注入位置在身份之后紧跟「你长这样：…」，最多 2 条、每条 80 字。
- 缩略图 160px JPEG（约 1.4 KB/张），远低于宿主 64 KB 参数上限。

**界面**

- 扇形图按人分块，每块 = 聊天次数 + 注入次数；排行榜显示名次、身份、QQ 号。
- 去掉内部数据展示（聊天 N + 注入 M），悬停只给百分比。
- 统计卡「名单外的人」换成运行时间，每秒刷新；移除顶栏运行时药丸。
- 文案更直白：「今日」→「今日活跃人数」，「身份档位」→「身份档」。

**修复**

- 删除按钮点击无反应：宿主 sandbox 无 `allow-modals`，`window.confirm()` 恒返回 `false`，改为页面内确认框。
- WebUI 保存会清空画像：保存时未带 `portraits` 字段。
- 页面加载失败会清空名单：接口返回不完整时状态变空壳，随后自动保存写回空名单。
- 长数字导致注入静默失效：画像描述含长数字会触发脱敏自检整条拒绝，改为就地打码。
- 能力声明缺失：`capabilities` 原为空数组，宿主不签发令牌，命令执行成功但回复被拒绝。

### v1.3.1

一次完整审计后的集中修复，重点是**不再丢用户数据**。

- **数据安全**：config.toml 改原子写；配置面板改动不再被回滚；自定义档位不再被清空；保存失败不再谎报成功。
- **身份注入**：堵住伪造 msg_id 冒充身份；堵住「发一句话让注入永久失效」；replyer 用精确消息 ID；重生成不再丢身份。
- **稳定性**：数据目录异常不再让插件整体失效；统计不再卡事件循环；坏数据不再打崩页面；统计加 2000 人上限 + 90 天 TTL。

### v1.2.0

- 页面重做：状态栏、扇形图、名单卡片一眼看清全局。

### v1.1.0

- 自动保存，不用再点保存。
